# Coffee Journal

Приватный дневник заваривания: внесение через Гермес, компактный просмотр и сравнение проб одного кофе на телефоне.

## Что работает сейчас
- Python CLI + SQLite: кофе, пачки, оборудование, рецепты, пробы; строгая валидация, повторяемые запросы без дублей, резервная копия, экспорт.
- Связь с текущим Гермесом через установленный skill `coffee-journal`: текст/диктовка/фото → уточнение неоднозначностей → CLI → чтение сохранённой записи. Автоматического импорта всех сообщений нет.
- Статический русскоязычный просмотр: выбор кофе/девайса, сортировка, сравнение до трёх проб, рецепт и детали. Сейчас открывается только **вымышленная демонстрация**.
- SQL для приватной проекции в Supabase: RLS, только чтение своих данных, публикация через разрешённого владельца с проверкой ревизии. Проверено на PostgreSQL/PGlite, НЕ развёрнуто в облаке.

## Запуск
```sh
python3 -m coffee_journal init
python3 -m coffee_journal list --entity coffee
python3 -m http.server 8765 --bind 127.0.0.1 --directory web
```
Открыть `http://127.0.0.1:8765/` на той же машине. В контейнере Гермеса это не публичная ссылка.

Python — только стандартная библиотека. Frontend — ES modules, без runtime-зависимостей и сборки. `web/` совместим с размещением на GitHub Pages, но сайт не опубликован.

## Проверки
```sh
python3 -m unittest discover -s tests -v
npm test --prefix web
npm ci --ignore-scripts --prefix tools/sql-check
npm test --prefix tools/sql-check
npm audit --prefix tools/sql-check --audit-level=moderate
uv run --with playwright==1.58.0 python tests/browser_smoke.py
```
Последний тест требует запущенный локальный сервер и Chromium (`CHROMIUM_PATH` переопределяет путь). Браузерная зависимость устанавливается только для тестов, не для приложения.

## Приватность
Канонические записи на текущем сервере: `/opt/data/coffee-journal-private/journal.sqlite3`, **вне Git**. Другие агенты получают код, но не эту базу. `COFFEE_JOURNAL_DB` задаёт другой путь для тестов/другого хоста. Даже экспорт без исходников содержит личные комментарии — нельзя выкладывать его в Pages.
